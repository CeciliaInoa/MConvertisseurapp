# Celsius to Fahrenheit Converter Application

This is a simple application that converts a temperature from degrees Celsius to degrees Fahrenheit. The app features a side navigation menu with two main options: **Converter** and **About**.

## 📱 Features

- Convert Celsius to Fahrenheit with a simple input.
- Side menu with two options:
  - **Converter**: The main interface to perform temperature conversions.
  - **About**: Information about the application.
- Clean and user-friendly interface.

---

## 🚀 Development Stages

The development of this application is divided into three key stages. Each stage is committed to Git to ensure clear tracking and validation of project progress.

### ✅ Step 1: Create the Main Application Interface
- Implement the main screen for temperature conversion.
- Input field for Celsius temperature.
- Button to perform conversion.
- Display area for Fahrenheit result.

### ✅ Step 2: Add Side Menu
- Add a navigation drawer or side menu.
- Include two options: **Converter** and **About**.
- Enable navigation between the two screens.

### ✅ Step 3: Customize About Page
- Design and populate the About page.
- Include information such as:
  - Application purpose
  - Developer name/contact (optional)
  - Technologies used
